Documentation Guide & Format Analysis Conventions

Project: LEGO Pirates of the Caribbean Reversing & Format Documentation

1. Game-Scoped Documentation Rule

This documentation suite covers formats, archives, and assets specific to LEGO Pirates of the Caribbean (2011, NXG HSEM v0x2E/v0x2F). It follows the two-tier LEGO reversing documentation hierarchy:

  • Scope of This Game Documentation: Pages under Formats/ document only the format versions present in LEGO Pirates of the Caribbean. Earlier Classic NU20 or later DX11/NTT variants not used by this title are kept to minimal notes so an implementer can write a targeted parser without cross-era clutter.
  • Parent Shared LEGO Documentation (../../reversing/docs/Travellers_Tales/): Combines format variants across all Traveller's Tales titles and engine generations. Consult the parent docs for cross-game comparisons.

2. Two Complementary Documentation Trees

  1. Format Analysis (Formats/): Follows binary format origins from executable and archive containers (.xex, .bin/ELF, .exe, .dat) to extracted formats (datFormats/).
  2. Game Files & Asset Use (Files/): Documents directory hierarchies, sound banks, character definitions, and level scripts through a combined virtual filesystem.

3. Expected Level of Detail (Standalone Clean-Room Standard)

Every understood format page in this module must be a complete, standalone specification capable of guiding a clean-room parser or converter implementation for LEGO Pirates of the Caribbean without inspecting RemakeEngine source code. Format pages must include:

  • Exact signatures, version constants, and mixed-endianness rules.
  • Full byte-offset structure tables, attribute encoding tables, and mathematical decoding formulas.
  • Shared-buffer resolution, shadow/LOD/breakup filtering, and triangle winding conventions.
  • Complete, end-to-end pseudocode covering binary parsing through final geometry reconstruction.
