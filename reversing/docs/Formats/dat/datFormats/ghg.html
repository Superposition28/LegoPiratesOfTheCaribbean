.ghg (Game Hierarchical Geometry — LEGO Pirates of the Caribbean)

Game Scope: LEGO Pirates of the Caribbean: The Video Game (2011) · Format Variant: NXG HSEM v0x2E / v0x2F. For Classic NU20 or Era 4/5 variants in other TT Games titles, see the parent LEGO documentation.

Game-Scoped Specification · NXG Engine

Complete, self-contained specification for skeletal character, creature, ship, and prop models (_nxg.ghg) in LEGO Pirates of the Caribbean. Wrapped in .CC4/HSER/02UN with an internal big-endian HSEM (v0x2E/v0x2F) render-mesh stream.

File Extension
.ghg (_nxg.ghg)
Stream Magic & Versions
"HSEM" (0x4853454D), ver in {0x2E, 0x2F}
Mixed Endianness
HSEM structural integers and index buffers are big-endian across platforms; PC Float3 vertex positions are little-endian inside the big-endian stream.

1. Binary Layout (LEGO Pirates of the Caribbean HSEM v0x2E/v0x2F)

StageOffset / RuleExact Binary Encoding
HSEM HeaderFirst 512 KBScan for "HSEM"; read uint32be ver (0x2E or 0x2F); skip 4 B if "ROTV"; read uint32be mesh_count (0 = empty locator rig). Limit = first "LTMU"/"PSID"; count "LOGH" from "PSID" -> n_logh = max(1, count).
vb_count & SlotsStart of mesh pExplicit uint32be vb_count iff HasExplicitVbc(buf, p) matches; else 1. pres >= 0x80000000 skips 8 B (back-ref rid = pres & 0xFFFF); pres == 0 skips 4 B; inline VB reads flags, nv, uint32be n_attr, n_attr * 3B (attr_def, tp, off), then nv * stride bytes + 4-byte offset.
unk1 & IBAfter VB slotsRead uint32be unk1, uint32be ib_pres. ib_pres >= 0x80000000 skips 4 B and resolves rid; inline IB reads flags, ic, isz (0->2) and ic BE indices. If unk1 != 0, skip shadow pass (12 B + 0/4 B align).
26 B Draw SliceWhen unk1 == 0ioff (u32be), icnt (u32be), vbase (u32be), vcnt (u16be @ +0x10), prim_tp (u16be @ +0x12: 0=List, 1=Strip), blen (u32be @ +0x16, clamp >256 to 0) + blen bone palette bytes. Nominal post-mesh trailer: 44 bytes.
Decoding & FiltersVertices & LOD 0TYPE_SIZES = [0,4,8,12,16,4,8,4,4,4,4,2]. Source Normal/UV from vb1 if missing in vb0 and vb1.nv == vb0.nv. Decode UByteN4 normals as (b/127.5) - 1.0. Slice cur_ib[ioff..ioff+icnt] (0-based relative to vbase; CCW, flip to CW for Godot). Keep LOD 0 (ceil(len(submeshes)/n_logh)), drop blen == 0 breakup parts when >=3 skinned submeshes exist, and deduplicate by bbox.

2. Complete Self-Contained Pseudocode (LEGO Pirates .GHG)

CONST TYPE_SIZES = [0, 4, 8, 12, 16, 4, 8, 4, 4, 4, 4, 2]

function IsHsemMeshStart(buf, pos):
    if pos + 24 > len(buf): return false
    w0, w1, w2, w3 = ReadU32BEArray(buf, pos, 4)
    if 1 <= w0 <= 4:
        if 0xC0000000 <= w1 <= 0xC000FFFF and w2 == 1: return true
        if w1 == 1 and w2 in [1,2,32,33,34,36,0x100,0x104] and 3 <= w3 <= 500000:
            return 1 <= ReadU32BE(buf, pos+16) <= 16 and buf[pos+20] == 0 and 1 <= buf[pos+21] <= 11
    if 0xC0000000 <= w0 <= 0xC000FFFF and w1 == 1 and w2 < 0x100000: return true
    if w0 == 1 and w1 in [2,32,33,34,36,0x100,0x104] and 3 <= w2 <= 500000:
        return 1 <= w3 <= 16 and buf[pos+16] == 0 and 1 <= buf[pos+17] <= 11
    return false

function HasExplicitVbc(buf, pos):
    if pos + 20 > len(buf): return true
    w0, w1, w2, w3 = ReadU32BEArray(buf, pos, 4)
    if 1 <= w0 <= 4:
        if 0xC0000000 <= w1 <= 0xC000FFFF and w2 == 1: return true
        if w1 == 1 and w2 in [1,2,32,33,34,36,0x100,0x104] and 3 <= w3 <= 500000:
            return 1 <= ReadU32BE(buf, pos+16) <= 16 and buf[pos+20] == 0 and 1 <= buf[pos+21] <= 11
    return false

function HalfToFloat(h):
    s = (h >> 15) & 1; e = (h >> 10) & 0x1F; f = h & 0x3FF
    if e == 0:  return 0.0 if f == 0 else (-1.0 if s else 1.0) * (f / 1024.0) * (2.0 ** -14)
    if e == 31: return 0.0
    return (-1.0 if s else 1.0) * (1.0 + f / 1024.0) * (2.0 ** (e - 15))

function DecodeTriangles(raw, vcnt, is_strip, clockwise_target):
    out = []; n = len(raw)
    if n < 3 or vcnt < 3: return out
    if is_strip:
        for s in 0 .. n - 3:
            a = raw[s]; b = raw[s+1]; c = raw[s+2]
            if 0 <= a < vcnt and 0 <= b < vcnt and 0 <= c < vcnt and a != b and b != c and a != c:
                out.extend((a, b, c) if (((s & 1) == 0) != clockwise_target) else (a, c, b))
    else:
        for i in range(0, n - (n % 3), 3):
            a = raw[i]; b = raw[i+1]; c = raw[i+2]
            if 0 <= a < vcnt and 0 <= b < vcnt and 0 <= c < vcnt and a != b and b != c and a != c:
                out.extend((a, c, b) if clockwise_target else (a, b, c))
    return out

function ParsePotcGhg(bytes, clockwise_target=false):
    hsem = FindTag(bytes[0 : min(len(bytes), 524288)], "HSEM")
    if hsem < 0: return []
    buf = bytes[hsem : min(len(bytes), hsem + 16*1024*1024)]
    p = 4; ver = ReadU32BE(buf, p); p += 4
    if buf[p : p+4] == "ROTV": p += 4
    mesh_count = ReadU32BE(buf, p); p += 4
    if mesh_count == 0 or mesh_count > 4096: return []
    limit = FirstFoundTag(buf, p, "LTMU", "PSID", default=len(buf))
    psid = FindTagFrom(buf, p, "PSID"); n_logh = max(1, CountTagOccurrencesFrom(buf, psid, "LOGH")) if psid >= 0 else 1

    all_vbs = []; all_ibs = []; rid_to_vb = {}; rid_to_ib = {}; submeshes = []
    for m in 0 .. mesh_count - 1:
        if p + 16 > limit: break
        vb_count = ReadU32BE(buf, p) and advance(p, 4) if HasExplicitVbc(buf, p) else 1
        vb_specs = []
        for slot in 0 .. vb_count - 1:
            pres = ReadU32BE(buf, p); p += 4
            if pres >= 0x80000000: p += 8; vb_specs.append(("ref", slot, pres & 0xFFFF))
            elif pres != 0:
                _flags = ReadU32BE(buf, p); nv = ReadU32BE(buf, p+4); na = ReadU32BE(buf, p+8); p += 12
                st = {pos_type:-1, pos_off:0, norm_type:-1, norm_off:0, uv_type:-1, uv_off:0, stride:0}
                for _a in 0 .. na - 1:
                    df, tp, off = buf[p], buf[p+1], buf[p+2]; p += 3
                    if 0 < tp < len(TYPE_SIZES):
                        if df == 0 and st.pos_type < 0:  st.pos_type = tp;  st.pos_off = off
                        elif df == 1 and st.norm_type < 0: st.norm_type = tp; st.norm_off = off
                        elif df == 5 and st.uv_type < 0:   st.uv_type = tp;   st.uv_off = off
                        st.stride = max(st.stride, off + TYPE_SIZES[tp])
                vb_obj = {slot:slot, nv:nv, stride:st.stride, data_pos:p, state:st, next_vbase:0, rid:null}
                all_vbs.append(vb_obj); vb_specs.append(("new", slot, vb_obj))
                p += nv * st.stride + 4
            else: p += 4; vb_specs.append(("none", slot, null))

        unk1 = ReadU32BE(buf, p); ib_pres = ReadU32BE(buf, p+4); p += 8; cur_ib = null
        if ib_pres >= 0x80000000:
            p += 4; rid = ib_pres & 0xFFFF
            if rid not in rid_to_ib and len(all_ibs) > 0: rid_to_ib[rid] = all_ibs[-1]
            cur_ib = rid_to_ib.get(rid, all_ibs[-1] if len(all_ibs) > 0 else null)
        elif ib_pres != 0:
            _ibf, ic, isz = ReadU32BEArray(buf, p, 3); p += 12
            if isz == 0: isz = 2
            cur_ib = ReadU16BEArray(buf, p, ic) if isz == 2 else ReadU32BEArray(buf, p, ic)
            all_ibs.append(cur_ib); p += ic * isz
        if unk1 != 0:
            p_after = p + 12
            if m + 1 < mesh_count: p = p_after if IsHsemMeshStart(buf, p_after) else p_after + 4
            continue

        ioff = ReadU32BE(buf, p); icnt = ReadU32BE(buf, p+4); vbase = ReadU32BE(buf, p+8)
        vcnt = ReadU16BE(buf, p+16); prim_tp = ReadU16BE(buf, p+18)
        blen = ReadU32BE(buf, p+22); if blen > 256: blen = 0
        resolved = []
        for (kind, slot, val) in vb_specs:
            if kind == "new": val.next_vbase = vbase + vcnt; resolved.append(val)
            elif kind == "ref":
                if val not in rid_to_vb:
                    cand = FirstMatch(all_vbs, x => x.slot == slot and x.rid == null and x.next_vbase == vbase and vbase+vcnt <= x.nv)
                        or LastMatch(all_vbs,  x => x.slot == slot and x.rid == null and vbase+vcnt <= x.nv)
                        or LastMatch(all_vbs,  x => x.slot == slot and vbase+vcnt <= x.nv)
                    if cand != null: cand.rid = val; rid_to_vb[val] = cand
                vb_obj = rid_to_vb.get(val)
                if vb_obj != null: vb_obj.next_vbase = max(vb_obj.next_vbase, vbase + vcnt)
                resolved.append(vb_obj)
            else: resolved.append(null)
        if vcnt >= 3 and icnt >= 3 and cur_ib != null and len(resolved) > 0 and resolved[0] != null:
            submeshes.append({vb0:resolved[0], vb1:(resolved[1] if len(resolved)>1 else null),
                              ib:cur_ib, vbase:vbase, vcnt:vcnt, ioff:ioff, icnt:icnt, prim_tp:prim_tp, blen:blen})
        p_after = p + 26 + blen
        if m + 1 < mesh_count:
            advanced = false
            for d in [44, 4, 8, 48, 72, 76]:
                if IsHsemMeshStart(buf, p_after + d): p = p_after + d; advanced = true; break
            if not advanced:
                for cand in range(p_after + 4, min(limit - 24, p_after + 300000)):
                    if IsHsemMeshStart(buf, cand): p = cand; advanced = true; break
            if not advanced: break

    lod0 = submeshes[0 : ceil(len(submeshes) / n_logh)]
    if count(sm in lod0 where sm.blen > 0) >= 3: lod0 = [sm for sm in lod0 where sm.blen > 0]
    out = []; seen_bboxes = {}
    for sm in lod0:
        vb0 = sm.vb0; vb1 = sm.vb1; st0 = vb0.state
        use_le = DetectLittleEndianF32(buf, vb0.data_pos, sm.vbase, sm.vcnt, vb0.stride, st0.pos_off, st0.pos_type)
        norm_vb = vb1 if (vb1 != null and vb1.nv == vb0.nv and vb1.state.norm_type >= 0) else vb0
        uv_vb   = vb1 if (vb1 != null and vb1.nv == vb0.nv and vb1.state.uv_type   >= 0) else vb0
        positions = [DecodePos(buf, vb0.data_pos + (sm.vbase+i)*vb0.stride + st0.pos_off, st0.pos_type, use_le) for i in 0 .. sm.vcnt-1]
        normals   = [Normalize3(DecodeNorm(buf, norm_vb.data_pos + (sm.vbase+i)*norm_vb.stride + norm_vb.state.norm_off, norm_vb.state.norm_type)) for i in 0 .. sm.vcnt-1]
        uvs       = [DecodeUV(buf, uv_vb.data_pos + (sm.vbase+i)*uv_vb.stride + uv_vb.state.uv_off, uv_vb.state.uv_type) for i in 0 .. sm.vcnt-1]
        tris      = DecodeTriangles(sm.ib[sm.ioff : sm.ioff + sm.icnt], sm.vcnt, (sm.prim_tp == 1), clockwise_target)
        if len(tris) < 3: continue
        bbox = QuantizedBBoxKey(positions, sm.vcnt, len(tris)/3)
        if bbox not in seen_bboxes: seen_bboxes.add(bbox); out.append((positions, normals, uvs, tris))
    return out
